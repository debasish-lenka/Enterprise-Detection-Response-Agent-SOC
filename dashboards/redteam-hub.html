Offensive Tooling — Authorized Use Only
Everything in this module is a red-team / adversary-emulation capability (attack simulation, credential capture, AI-driven pentesting). It's kept separate from the blue-team dashboards above for a reason: these tools generate traffic and artifacts that should never touch a production network, and separating them makes it obvious in an audit which tools are defensive vs. offensive. Run only against the isolated lab VLAN with explicit authorization.
