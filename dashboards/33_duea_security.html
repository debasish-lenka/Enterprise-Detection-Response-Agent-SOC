Mutual TLS authentication with pinned certificates

Policy Signing with Ed25519

✓ Enforced

🛡️ Security Guarantees

🔑 End-to-End Encryption

All communication between agents and manager is encrypted using TLS 1.3 with AES-256.

🛡️ No Data Leakage

Sensitive data is never logged in plain text. Credentials are encrypted in transit and at rest.

📝 Immutable Logs

Cryptographic hashes prevent log tampering. Every event is timestamped and verified.

🔐 Code Transparency

100% open-source (AGPL-3.0) for full code auditability by the community.

✓ Policy Signing

Only digitally signed policies execute — protects against policy injection attacks.

⚠️ Secret Redaction

Automatic detection and scrubbing of passwords, API keys, and tokens from logs.

🎯 Threat Model & Mitigations
Agent Compromise
Threat: Attacker gains access to agent and modifies local configuration.
Mitigation: Code signing + immutable audit logs + tamper detection.
Man-in-the-Middle (MITM)
Threat: Attacker intercepts communication between agent and manager.
Mitigation: mTLS with certificate pinning + TLS 1.3 + AES-256 encryption.
Policy Injection
Threat: Attacker injects malicious policies into agents.
Mitigation: Ed25519 digital signature verification before execution.
Lateral Movement
Threat: Compromised endpoint becomes a pivot point for network attacks.
Mitigation: Privilege isolation + capability-based execution + network segmentation.
